# Bangalore Metro – Daily Passenger Commute Analysis 🚇

## 📌 Project Overview

This project analyzes Bangalore Metro passenger commute data for **September 2025** using Microsoft Excel. The objective is to understand passenger movement patterns, identify busy stations and peak travel hours, and compare ridership across metro lines.

Using **Power Query, Pivot Tables, Pivot Charts, slicers, and KPI cards**, I cleaned and combined multiple datasets to create a five-page interactive dashboard for exploring passenger activity across the Purple, Green, and Yellow Lines.

## 🎯 Project Objectives

- Identify peak passenger travel hours.
- Analyze ridership across different days of the week.
- Identify the busiest metro stations.
- Compare passenger activity across metro lines.
- Examine passenger movement at interchange stations.
- Analyze payment-mode distribution and revenue-related patterns.
- Support data-driven crowd management and service planning.

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data analysis and dashboard development
- **Power Query** – Data cleaning, transformation, and merging
- **Pivot Tables** – Data summarization and aggregation
- **Pivot Charts** – Visualizing passenger travel patterns
- **Slicers & Filters** – Interactive data exploration
- **KPI Cards** – Displaying key performance indicators

The datasets were cleaned and combined using Power Query to create a structured dataset for analysis.

## 🧹 Data Cleaning & Transformation

The main data preparation steps included:

- Split station information using delimiters.
- Corrected misspelled station names.
- Pivoted hourly columns into a structured format.
- Transformed payment categories into a format suitable for analysis.
- Removed unnecessary columns that were not required for the dashboard.
- Merged datasets using station names and dates.
- Removed duplicate and unwanted columns.
- Applied filters to improve data consistency.


## 📈 Key Findings

- Passenger activity varies significantly across different hours of the day.
- Certain stations experience higher passenger demand than others.
- Ridership patterns differ across the Purple, Green, and Yellow Lines.
- Interchange stations are important locations for monitoring passenger movement.
- Payment methods contribute differently to the recorded transaction amounts.
- Passenger activity varies between weekdays and weekends.
- Hourly and station-level analysis can help identify areas requiring closer attention for crowd management.
